Tokyo Cafe Radar（iOS アプリ）

お問い合わせ

不具合の報告、掲載情報の誤り・修正・取り下げのご依頼、ご要望は GitHub Issues で受け付けています。投稿には GitHub アカウント（無料）が必要です。

新しい Issue を作成 既存の Issue を見る

店舗・施設のご担当者で、掲載内容の修正や取り下げをご希望の場合は、Issue に店名と該当箇所をお書きください。確認のうえ、原則として翌日の更新までに反映します。

よくある質問

データはいつ更新されますか？
毎朝1回、新しい店舗・イベントを追加しています。アプリを開き直すと最新のデータを読み込みます。地図右上の「更新: 日付」が配信日です。
情報が実際と違います
公式発表や報道をもとに整理していますが、営業時間や期間は変わることがあります。各項目の「出典を見る」で元の記事を確認できます。誤りに気づかれたら Issue でお知らせください。
現在地が表示されません
このアプリは現在地を使いません。東京都内の新しい店とイベントを眺めるためのアプリとして設計しています。
「行きたい」リストが消えました
リストは端末の中だけに保存しています。アプリを削除すると消えますので、更新は削除せず上書きで行ってください。
東京以外には対応しませんか？
いまは東京都内のみです。ご要望は Issue にお寄せください。
